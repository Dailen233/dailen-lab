# JobInsight 开发基础学习

本目录用于记录参加华为 ICT 大赛及开发 JobInsight 项目前的基础学习过程。

## 学习路线

### 1. Python 基础

学习 Python 语法、数据结构、函数、模块、文件操作和异常处理，为后端开发打好基础。

对应目录：`01-python-basics/`

### 2. FastAPI 框架

学习创建 API、路径参数、查询参数、请求体、数据校验和接口测试。

对应目录：`02-fastapi/`

### 3. 前端基础

学习 HTML、CSS 和 JavaScript，并掌握通过 HTTP 请求调用 FastAPI 接口。

对应目录：`03-frontend/`

## 学习方式

- 根据老师提供的资料学习
- 每个知识点编写可运行的练习
- 在对应目录维护 README
- 每完成一个阶段进行一次 Git 提交
- 最终完成一个前后端联调示例
